# Web Features & UI Components

This repository is a **guide and collection of reusable web components, features, and UI designs**.  
Each feature is written in different technologies (HTML, CSS, JavaScript, PHP, etc.) to serve as a reference for building modern, responsive, and user-friendly web applications.

## 📌 Purpose
The goal of this repository is to:
- Provide ready-to-use examples of common web features (e.g., dark mode, mobile navigation, accordion).
- Serve as a learning resource for developers exploring frontend and backend integrations.
- Act as a personal library of UI/UX patterns that can be reused in future projects.

## 📂 Structure
Each feature is organized in its own folder:

Inside each folder, you may find:
1. html-css-js/
    - `index.html` → demo file  
    - `style.css` → styles for the feature  
    - `script.js` → JavaScript logic 
2. react/
    - `sample.jsx`
    - `sample.ts`
3. php/
    - `index.php`
    - `style.css`
- `README.md` → description of how the feature works
